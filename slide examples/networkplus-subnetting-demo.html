SUBNETTING &
CIDR NOTATION

Breaking large IP blocks into smaller, purpose-built networks — N10-009 Domain 1.4 

What Is Subnetting?

  • Splits one large network into smaller, more manageable sub-networks
  • Reduces broadcast traffic and shrinks the failure/attack surface
  • Done by borrowing bits from the host portion of an address
  • Every subnet has a network address, a broadcast address, and a usable host range

CIDR Notation

192.168.1.0/24
address prefix length = network bits
  • The number after the slash = how many bits are network bits
  • Replaced the old "classful" A / B / C system
  • Bigger number after the slash → smaller subnet, fewer hosts
  • Range runs from /1 (huge block) to /32 (single host)

Worked Example

Take 192.168.1.0/24 and carve it into 4 equal subnets

$ bits_needed = ceil(log2(4)) = 2
$ new_prefix = /24 + 2 = /26
$ subnet_size = 2^(32-26) = 64
 
# resulting subnets:
192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26

Exam Tip

Gotcha alert: the exam loves handing you a /27 or /28 and asking for the broadcast address. Solve the host bits first — everything else (network ID, broadcast, usable range) falls out from there.
